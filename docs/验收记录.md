## 2. 页面与交互（Chrome CDP）

| 流程 | 操作 | 结果 |
|---|---|---|
| 登录 | `ops_admin` + 演示口令 | 跳转地图；会话菜单显示 R1/R6；无未处理异常 |
| 登录失败 | `user_r1` + 错误凭证 | 显示 `AUTH_INVALID`、message、trace_id；回匿名态 |
| 会话恢复 | 刷新页面 | AUTH-04 恢复会话；权限摘要用于导航裁剪 |
| 登出 | 菜单“退出当前会话” | 本地会话清除；旧句柄被后端拒绝 |
| 上报 | 文件（JPEG）+ 定位 + 类别/规模 | FILE-01 登记 media_ref；RPT-01 返回 `SUBMITTED`/匹配 SEC-001；DOM/存储无原始坐标 |
| 个人中心 | 打开列表/筛选/分页 | RPT-02 列表、三段进度、闭环直接渲染 |
| 评价 | 已闭环工单 + 演示辅助填入 | FB-01 返回 feedback_id |
| 审核 | `rev_l1` + 演示目标 + 初审通过 | 返回 `IN_PROGRESS`、`next_review_level=LEVEL_2` |
| 工单转派 | `ops_admin` + 演示目标 + 组织 | 返回 `DISPATCHED` |
| 工单办结 | 证据文件 + 3.25 kg | 返回 `CLOSED`、`closed=true`、`COMPLETED` |
| 注册 | CLI 签发验证码 + 表单 | 成功面板：账号/ACTIVE/默认 R1 |
| 空列表 | 新注册账号进入个人中心 | 显示“还没有上报记录”空态 |
| 未发布指标 | 公示切到无数据周期 | 数值隐藏，显示“未发布/样本量 0” |
| 审图号缺失 | 临时清除审图号后打开地图 | 无点位、无岸段表格；显示合规闸门；随后恢复占位值 |
| 传输异常 | 停止 `server.py` 后点刷新 | “无法连接后端服务” + 重试；无伪造业务码 |
| 本地校验 | 空账号/凭证提交 | 字段级错误，未发起 API 请求 |

浏览器控制台：上述流程无未处理异常；仅错误登录产生浏览器对 401 的正常网络日志。截图见
`docs/screenshots/`，索引见 `docs/screenshots/README.md`。
