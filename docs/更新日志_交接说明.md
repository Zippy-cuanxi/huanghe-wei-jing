## 3. 技术形态

- 前端：Vue 3 全局构建（`assets/vue.global.prod.js`）+ 原生 ES Modules；无 npm、无构建步骤。
- 入口：`index.html`；应用与路由：`assets/app.js`。
- 公共内容：`assets/content.js`（栏目、示例文章、行动案例、指标口径、传播素材等）。
- 样式：既有 `assets/styles.css` + 本轮新增 `assets/public.css`（后加载，覆盖公共线/工作线新增样式）。
- 组件：`assets/components.js`（全局注册）；空状态在 `empty-state.js` / `EmptyState.vue`。
- 图片：`assets/img/` 下本地 SVG 插画与 Logo PNG。
- 后端：`server.py` + `backend/`；14 个接口，SQLite；业务规则、状态机、鉴权、审计未改。
- 没有 CMS、内容接口、纠错接口、通知接口、事件接口；相关内容以静态示例/只读占位呈现。
