## 0. 测试前准备

- [ ] 启动服务：双击 `run.bat` 或执行 `python server.py`，访问 `http://127.0.0.1:8000/`。
- [ ] 准备一张小尺寸 JPG/PNG 图片，用于上报测试。
- [ ] 浏览器允许定位（上报流程需要）；或准备在 DevTools 中模拟定位。
- [ ] 桌面视口 1440px；移动端用 DevTools 模拟 390×844。
- [ ] 记录测试前 `var/app.db` 状态；测试后可运行 `reset_demo.bat` 清理测试上报。
- [ ] 如无 git，先备份当前目录。

## 1. P0 启动与核心链路

- [ ] **P0-01 首页可打开**：访问 `#/`，显示品牌、主张、看地图/去上报/看成效、指标、闭环、最新动态；无控制台报错。
- [ ] **P0-02 登录可用**：`ops_admin` / `Demo#Pass2026` 登录成功，顶部显示账号；退出后恢复匿名。
- [ ] **P0-03 匿名可浏览**：退出登录后访问 `#/map`、`#/knowledge`、`#/publicity`、`#/news`，均能打开。
- [ ] **P0-04 地图默认示意地图**：`#/map` 默认显示「示意地图」（示意网格）；切到「分布矩阵」后当前周期列高亮。
- [ ] **P0-05 地图下钻**：点击有颜色矩阵格 → 岸段档案；点击列头 → 周期公示详情；点击行头 → 岸段档案。
- [ ] **P0-06 演示增强默认可见**：默认 `#/map` 显示三视图切换按钮与真实河道入口；URL 加 `?demo-map=0` 可关闭，界面保留 G3 提示。
- [ ] **P0-07 匿名上报步骤 3 就地登录**：`#/report` 匿名走到步骤 3，填写 `ops_admin` 登录后页面不跳走，已填内容保留。
- [ ] **P0-08 上报可提交**：选图、获取定位、选类别/规模、确认提交，显示「上报已收到」与受理编号。
- [ ] **P0-09 我的参与可查**：`ops_admin` 的 `#/profile` 能看到刚刚提交的上报与三段进度。
- [ ] **P0-10 后台可进入**：`ops_admin` 的 `#/admin` 显示业务/内容/数据/系统四组导航。

## 13. 预期限制（不是 bug）

以下为当前接口/需求边界，测试时不应视为功能缺陷：

1. 内容管理、来源台账、事件证据、指标版本、导入导出、纠错提交、通知发送、事件记录等接口**未接入**；对应后台只读/占位，纠错弹窗会说明不伪造成功。
2. 公共订阅只写 localStorage，**不会发送真实通知**。
3. 周期战报模板、传播素材中的「待填」是模板占位，不应填成真实数字。
4. 事件记录详情为**示例**，不是真实事件。
5. 当前数据库为**演示夹具**；行动案例中的 12.5 kg / 8 kg 等为演示数据。
6. 默认公开页含真实底图（演示增强）；`?demo-map=0` 可关闭，G3 书面豁免仍待确认。
7. Logo 为 AI 生成位图，已修正错字并裁除水印；矢量源与授权待确认。
8. `page_size=100` 用于矩阵完整岸段；超过 100 个岸段的分页尚未专门处理。
9. 工作线仍保留内部编号/CR 提示；公众线已去技术化。
10. 视觉对比度、完整无障碍与旧截图更新仍需人工验收。
