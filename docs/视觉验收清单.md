# 视觉验收清单（待人工执行）

> 本清单用于回应独立评审中的「视觉可读性未验收」项。以下项目尚未完成人工验收，不得在交付说明中宣称“已通过”。

## 1. 深浅主题

- [ ] 正文、次级文字与背景对比度满足可读性要求。
- [ ] 图例文字、刻度、空白格/零值格/数据不足斜纹在浅色与深色主题下均可区分。
- [ ] 春彩虹色带在深浅主题下都能分辨低/中/高段，且不依赖颜色单独判断。
- [ ] 图片插画在深色主题下不刺眼、不与背景粘连。

## 2. 内容与分享卡

- [ ] 首页首屏在 1440 / 1024 / 390 宽度下均无成段说明文字。
- [ ] 海报/分享卡的标题、口径、来源、示例声明四区在缩放后仍可读。
- [ ] 分享卡的主视觉不遮挡文字；二维码/链接位为占位且不虚构。
- [ ] 行动、资讯、科普详情图的说明文字与「示意图」标识清晰。

## 3. 移动端

- [ ] 390px 下无横向溢出；矩阵可横向滚动且首列/表头可识别。
- [ ] 筛选折叠、就地登录、弹窗与返回按钮触控目标充足。
- [ ] 图片裁切不丢失主视觉焦点；标题与按钮不被图片遮挡。

## 4. 图标与品牌

- [ ] 图标线宽、圆角与 24×24 网格一致；状态不只靠颜色。
- [ ] 头部/页脚 Logo 在深色主题下清晰；关于页完整标识无错字、无水印。
- [ ] Logo 原图授权、矢量源与品牌标准已确认（见品牌资产说明）。
