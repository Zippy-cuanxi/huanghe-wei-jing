# 黄河戍境 · 黄河上游岸线垃圾治理参与平台（可运行交付）

> **交接前请先读**：[docs/更新日志_交接说明.md](docs/更新日志_交接说明.md)。
> **功能验收请用**：[docs/功能测试清单.md](docs/功能测试清单.md)。

本目录是**前后端接口对接后、并完成公共线信息架构重构的可运行结果**：

- 前端：Vue 3 单页（单一 `index.html` 入口，Hash 路由），公共线与工作线分离；
- 公共线：首页 → 垃圾地图 / 分类科普 / 护河行动 / 成效公示 / 资讯与政策 → 详情 → 参与；
- 工作线：独立版式的运营工作台（审核、工单、看板、字典），仅对有权限者显示；
- 后端：沿用原 Python 业务实现，新增 HTTP 适配层，不改业务规则、状态机、鉴权与审计；
- 契约：14 个接口（AUTH-01–04、FILE-01、RPT-01/02、MAP-01、WO-01/02、REV-01、STAT-01、FB-01、ADM-01）；
- 数据：SQLite 本地库，首次启动自动写入演示夹具；演示账号口令 `Demo#Pass2026`。

> 公共线文案中的示例内容统一标注「示例」；业务数字只来自后端。样式在 `assets/public.css`，
> 与既有 `assets/styles.css` 叠加使用。
>
> 内容插画位于 `assets/img/`，为本地原创 SVG 示意图，不是真实照片、不是真实地理；
> 行动故事中的示范数据取自本项目 2026-11 演示夹具，并标注「演示数据」，不是生产结论。
>
> 品牌标识：`assets/img/logo-mark.png` 用于顶部/页脚，`assets/img/logo-lockup.png` 用于关于页。
> 原始 AI 图的文字为「潢河戍境」（首字误带三点水），未直接使用；现用原图图形标 + 正确「黄河戍境」重排，
> 并已裁除「豆包 AI 生成」水印。若后续拿到矢量 Logo，可替换同名 PNG。详见 `docs/品牌资产说明.md`。
>
> 地图口径：热力权威口径为「岸段 × 周期」二维矩阵；打开 `#/map` 默认进入**示意地图**（示意网格），可切换到分布矩阵。
> 标准地图、卫星影像与真实河道为**演示增强视图**，默认可见；如需临时关闭可在 URL 加 `?demo-map=0`；
> 该模式 **G3 豁免待项目方书面确认**，不作为正式地图、测绘成果或公开地理依据。
> 初版「沿河 × 离岸」方案不采用；视觉对比度与移动端验收见 `docs/视觉验收清单.md`。

> 详细 HTTP 路径、请求字段、响应字段、类型、校验、错误码与状态反馈见
> [`docs/接口对接说明.md`](docs/接口对接说明.md)。

## 1. 一键运行

要求：Python 3.11+（已在 3.14.6 验证），无第三方 Python 依赖；浏览器需支持 ES Modules 与 Web Crypto。

```bat
双击 run.bat
```

或命令行：

```bash
cd "C:\Users\85046\Desktop\黄河戍境——基于空间网格聚合的黄河垃圾热力地图交互式可视化系统"
python server.py
```

启动后自动打开 `http://127.0.0.1:8000/`（也可手动访问）。首次启动会初始化
`var/app.db`、写入演示数据并生成 `demo/demo_ids.json`，约需数秒。

> 不建议直接双击 `index.html`：ES Modules、`fetch` 与定位在 `file://` 下会被浏览器限制；
> 必须通过 `server.py` 同源访问。

### 重置演示数据

关闭服务后运行 `reset_demo.bat`（删除 `var/app.db` 与演示 ID，下一次启动重新生成），
或手动删除 `var/app.db*` 后重启。

### 前端技术说明

- 使用 Vue 3 全局构建 + 原生 ES Modules；无框架构建步骤、无 npm 依赖。
- 单页 Hash 路由见上方「公共线路由」；静态页 + 5 组动态详情路由（岸段/科普/行动/资讯/公示周期）。
- 公共线与工作线分离：公共线使用内容型版式与公共页脚；`/admin` 使用独立工作台头部与侧栏，
  不显示公共线导航与页脚。
- 公共线视觉：水系深蓝 + 生态青绿 + 沙金；春彩虹系连续色带（嫩芽绿 → 迎春黄 → 杏橙 → 桃粉 → 淡紫）；
  首屏不铺陈成段说明，口径与来源收进就近折叠入口。
- 所有响应严格校验 `code/message/data/trace_id` 四字段；不使用第二套数据格式。
- 凭证仅 `sessionStorage`；原始坐标只在 RPT-01 表单闭包内短暂存在，提交后立即清除，
  不显示、不写 URL/日志/存储。
- 顶部导航向下滚动时自动收起，向上滚动或回到顶部时恢复（240ms 过渡；`prefers-reduced-motion`
  下取消动画）。右上角「目录」菜单集中列出与顶部导航一致的 6 个栏目，当前栏目高亮并标注「当前」；
  支持点击切换、点击外部 / `Esc` 关闭，公共线与工作线共用同一组件，窄屏下入口保持在最右侧。
- 首次访问先经过**登录闸门**：提供游客登录、账号登录（用户名 + 密码）与注册账号三种方式，
  闸门只承载登录相关操作。未准入时不渲染站点导航与页面内容，Hash 跳转（含直接输入地址、
  前进/后退）统一回到 `#/`，登录卡片不可关闭。
- 游客凭证保存在 `sessionStorage`（`hh.guest_session`），只对当前标签页有效；刷新或再次进入
  不重复弹出，关闭标签页后失效。账号登录 / 注册沿用既有 `hh.session_handle` 会话，同样只存
  `sessionStorage`；注册接口不签发会话，前端在注册成功后使用同一凭证自动登录。
  已有有效业务会话（AUTH-04 校验通过）时不弹闸门。游客身份只是访问准入，不授予上报、审核等
  业务权限；准入后的公共线头部仍保留真实登录 / 注册入口。
- `closed/progress_stage/heat_value/...` 全部直接渲染后端值；前端不做业务推导。
- 公共线在 ADM-01 字典不可用时使用通用展示标签/选项（与后端枚举取值一致），
  提交仍由后端校验；字典可用时优先使用后端 label。工作线保留原有字典回退逻辑。
- 垃圾地图的示例岸段有「示意网格 / 标准地图 / 卫星影像」三视图，默认仍是示意网格；
  示意网格新增**二维空间网格聚合热力**：把岸段记录落入网格单元，按单元聚合值连续着色，
  不做插值；空白格子单独表达为「无公开记录」。网格单元与标准 / 卫星地图共用同一份 MAP-01
  清洗结果。后两者由 `assets/views/section-satellite.js` 的 `GANSU_SCOPE` 统一约束，界面与配置均标注
  **仅支持甘肃省**：影像瓦片 `bounds`、默认定位、`maxBounds`、`minZoom/maxZoom` 与岸段落点
  都以甘肃省外接矩形为边界（约 92.2–108.8°E / 32.5–42.95°N，非行政区界线、非测绘成果），
  省外岸段不落点、不参与交互。粗化坐标按 WGS84 → GCJ-02 对齐高德影像，数据仍只来自 MAP-01。
  该真实底图能力按用户确认保留，公开文案将其定位为「地理语境」，不作为正式测绘成果。
- `assets/views/trash-heat.js` 提供「垃圾分布热力」叠加层：直接消费页面中已有的 MAP-01
  `sections`（不新增接口、不补造点位），优先按 `heat_value` / `cleanup_kg_total` 等可用权重字段，
  字段全部缺失时退化为**位置记录密度**；颜色为春彩虹系连续色带（不是蓝色斑点、不是分档方块）。
  默认「岸段 × 周期」矩阵按当前筛选周期回溯最近 6 个月，空白列不拼接、不补造；矩阵单元格与示意地图（SVG 二维网格）及标准 / 卫星地图（Leaflet Canvas 窗格 610）共用同一份 MAP-01 清洗结果；
  Canvas 随 `move` / `zoomend` / `viewreset` / `resize` 重绘，坐标按 GCJ-02 对齐底图，
  `pointer-events:none` 不拦截滚轮、拖拽、标记点击与弹窗；卡片头部可一键开关，卸载时销毁。
  无效 / 缺失 / 越界坐标、重复主键、同坐标记录均稳妥处理，单点上限 2000。
  河道图按原设定保持「仅呈现河道、不含垃圾点位」，不叠加该层。
- 公共线上报支持匿名预览：匿名可选图、走完前两步并看到登录提示；提交仍需登录。
  原始定位不写入草稿/本地存储；登录后需重新选择文件与定位。

### 热力图帧序列导出（MATLAB）

- `tools/matlab/export_heatmap_frames.m`：把 `Z(lat,lon,time)` 导出成网页叠加用的透明 PNG
  帧序列 + `meta.json` + `colorbar.png`，输出到 `var/heatmap_frames/`（多变量按 `key` 分子目录）。
- 默认 `pcolor` + `shading interp` + `turbo` + `axis off` + `exportgraphics` 透明背景无边距；
  全序列共用固定 `clim`；NaN 严格透明；单帧硬上限 300 KB（超限时先量化颜色、再等比缩小像素，
  并保证所有帧尺寸一致）。`pcolor` 不可用时自动降级为等价光栅化。
- `cfg.dataSource` 支持 `demo` / `workspace` / `mat`；`cfg.varName` 可写成 cell 一次导出
  含沙量 / 流速 / 水深；经纬度默认 lon 100–119、lat 33–41。
- `meta.json` 含 `bounds`（`bounds_leaflet` 可直接喂给 `L.imageOverlay`）、`frames` / `times`、
  `clim`、`units`、`pixel_size`、坐标系等。产物是不含底图与境界线的透明数据层，
  须叠加在合规底图（高德 / 腾讯 / 天地图）之上，不得单独发布；底图为 GCJ-02 时
  前端须对 bounds 做坐标偏移（外接矩形近似）。

### 后端适配说明

- 业务服务、状态机、权限、审计、幂等、样例均沿用原实现；`server.py` 只做：
  URL ↔ 接口编号映射、请求体/查询参数到 `payload` 的转换、Header → 会话/幂等键、
  统一信封与 HTTP 状态码、静态文件托管。
- `backend/db.py` 只把 SQLite 连接设为允许跨线程持有；`server.py` 用应用锁串行化
  `BackendApp.handle`，不改变事务边界或业务规则。
- 没有新增业务接口/字段；`/demo/demo_ids.json` 仅为本地演示辅助（非契约接口）。

|---|---|
| AUTH-01 注册 | `POST /api/auth/register` |
| AUTH-02 登录 | `POST /api/auth/login` |
